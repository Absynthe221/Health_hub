## 🚀 How to Use

### **Access Analytics:**
```
1. Go to: http://localhost:3000/dashboard/admin
2. Click "Analytics" tab
3. See comprehensive dashboard
```

### **View Specific Metrics:**
1. **Overview**: Scroll to see KPIs
2. **Trends**: Check daily/weekly charts
3. **Performers**: See top 5 students
4. **Struggling**: Identify students needing help
5. **Modules**: View popularity rankings
6. **Devices**: Check access patterns
7. **Times**: Identify peak hours
8. **Geography**: See user locations

3. Download CSV or PDF reports
